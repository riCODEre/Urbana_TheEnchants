# Urbana: The Enchants

A 2D action game built with C# and Windows Forms where you play as a wizard battling enemies with magic spells.

## Description

Urbana: The Enchants is a top-down 2D action game where players control a wizard character who must defeat enemies using magic spells. The game features a scoring system, multiple difficulty levels, and resource management mechanics including health, mana, and powerups.

## Features

- Fast-paced 2D gameplay with top-down perspective
- Character movement in four directions (up, down, left, right)
- Magic spell casting system
- Enemy AI that follows the player
- Health and mana management
- Powerup system that can restore health
- Progressive difficulty with increasing enemy speed
- Background music
- Score tracking system
- Multiple difficulty levels that unlock as you progress

## How to Play

### Controls
- **W**: Move up
- **A**: Move left
- **S**: Move down
- **D**: Move right
- **Space**: Cast spell (costs 10 mana)
- **Enter**: Restart game (after game over)

### Gameplay
1. Control your wizard character using WASD keys
2. Cast spells with the Space bar to defeat enemies
3. Collect mana potions to restore your mana
4. Fill your powerup bar by defeating enemies to gain health restoration
5. Avoid enemies as they will damage your health on contact
6. Survive as long as possible and achieve a high score
7. The game gets progressively harder as your score increases

## System Requirements

- Windows Operating System
- .NET Framework (latest version recommended)
- Minimum 4GB RAM
- 100MB free disk space

## Installation

1. Clone the repository
2. Open the solution file (Urbana_TheEnchants.sln) in Visual Studio
3. Build the solution using Build > Build Solution
4. Run the application using Debug > Start Debugging or press F5

## Technologies Used

- C# programming language
- .NET Framework
- Windows Forms for UI and game rendering
- System.Media for audio playback
