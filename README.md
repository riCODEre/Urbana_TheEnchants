# Urbana: The Enchants

A Windows Forms application project built with C#.

## Description

Urbana: The Enchants is a desktop application that provides an interactive user interface using Windows Forms
technology.

## System Requirements

- Windows Operating System
- .NET Framework (latest version recommended)
- Minimum 4GB RAM
- 100MB free disk space

## Installation

1. Clone the repository
2. Open the solution file (Urbana_TheEnchants.sln) in Visual Studio
3. Build the solution using Build > Build Solution
4. Run the application using Debug > Start Debugging or press F5
